# Don Libarti

An offline 3D driving prototype for Android, built with Godot 4.

## First prototype
- A detailed procedural sports car with layered bodywork, glass, lights, bumpers, alloy wheels and spoiler.
- A long, perfectly straight test road.
- No trees, traffic, buildings, bends or online features.
- Automatic forward driving with left/right touch controls.
- Keyboard A/D or arrow-key steering for desktop testing.

## Build
Open this folder in Godot 4.4.1. For Android, configure the Android SDK and export templates, then export using the Android preset.

GitHub Actions can build an APK from the Actions tab using **Build Don Libarti Android APK**.

This is an early playable prototype, not a finished GTA-scale game.
